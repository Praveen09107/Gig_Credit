  Layout: AuthBrandBand + AuthFormCard (existing spec)
  Fields: Full Name · Mobile Number

    Enter name + mobile → SEND OTP

  Flow:

    OTP correct → POST /api/auth/signin
    On success:
      Token refreshed
      Check user.completedSteps
      Navigate based on state (Section 1 tree)
      Toast: SIGNIN_SUCCESS

Full spec in Steps prompt. Summary flow here for routing clarity.

  /home (GET STARTED pressed)
    → GetStartedPopup appears
    → "Continue" pressed  → /apply/step-1
    → "Guidelines" pressed → /guidelines  (can return to popup path)

  /apply/step-1
    → fill + verify → STEP1_COMPLETE toast
    → 3A loader → /apply/step-2

  /apply/step-2
    → fill + verify → STEP2_COMPLETE toast
    → 3A loader → /apply/step-3

  /apply/step-3
    → fill + verify → STEP3_COMPLETE toast
    → 3A loader → /apply/step-4

  /apply/step-4
    → fill + verify → STEP4_COMPLETE toast
    → 3B loader (vault submit)
    → 3C loader (AI scoring — real time)
    → AI_SCORE_DONE toast
    → /report  (replace stack)

  Back behaviour at each step:
    Back press → BackGuardPopup appears (existing spec)
    "Go Back" → previous step (step > 1) or /home (step 1)
    "Keep Going" → stay on current step

  Interrupted session resume:
    User closes app mid-step → data saved server side
    On re-login → restored to exact step they left
    All previously filled fields re-populated from server

  user.name             :  string  → greeting in home hero
  user.completedSteps   :  0–4    → routing + home card state + progress bar
  user.score            :  number → score hero + loan max amount

    On splash (after token check)

    On every step complete (full refresh)

  All dynamic text in hero bands, cards, buttons
  reads from this state — not hardcoded.
