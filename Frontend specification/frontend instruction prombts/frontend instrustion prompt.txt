delivery partners, street vendors, daily-wage earners in India.

        no life · static hero images · loading text ("Loading...") ·

          Every loader is a mini narrative.

── MOVING BORDER GLOW (on press — the "outline shadow moving" effect) ────────

  This is the signature effect for every interactive card.

  Implementation:
    Before element (pseudo ::before or animated border):
      position: absolute  inset -1px  radius same as card  z-index -1
      background: conic-gradient(
        from var(--angle),
        transparent 0%,

    Like a pulse of energy going around the card edge.

  Apply to: ALL interactive cards without exception.

── SHAP INSIGHT CARDS: TILT EFFECT ──────────────────────────────────────────

  Each SHAP insight card responds to device gyroscope (mobile)
  or mouse position (web):

  3D tilt using CSS transform perspective:
    perspective: 600px
    rotateX: ±8deg  rotateY: ±8deg
    Based on pointer position relative to card centre
    transition: none while moving  0.15s ease-out on leave (snap back)

  Inner shadow shifts with tilt:
    box-shadow moves opposite to tilt direction
    Gives depth — card appears to float

  On tap: moving border glow fires + card expands to show more detail

SECTION 12 — PERFORMANCE RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Impressive effects must not kill performance. Every rule below is hard.

  ONLY animate:  transform  opacity  filter  (these use GPU compositor)
  NEVER animate: width  height  top  left  margin  padding  (causes reflow)
  Exception:     height on accordion expand → use max-height trick instead

  will-change:
    Add will-change: transform to: hero band, cards, buttons, bottom sheet
    Remove will-change after animation completes (memory cleanup)

  Particle system:
    Max 20 particles per screen
    Use CSS animations (not JS animation loop)
    Paused when screen not in focus (Page Visibility API)

  IntersectionObserver:
    One shared observer instance for all scroll reveals
    Disconnect after element animates in (cleanup)

  Skeleton duration:
    Show skeleton immediately on data-fetch start
    Never show skeleton for fetches expected < 200ms
    (Check cached data first — show real content instantly if cached)

  Reduce motion (prefers-reduced-motion: reduce):
    ALL translateX/Y/scale animations: skip (values jump to final state)
    ALL spring/bounce: disabled
    Gradient breath: paused
    Particle system: hidden
    Confetti: hidden
    Progress bar: still fills (timing only, value is useful)
    Opacity transitions: kept at 200ms (not instant)

  Frame budget:
    All animations must maintain 60fps on mid-range Android
    (Redmi 10, Samsung A-series equivalents)
    Test on these devices — not just flagships
