STEP-6 — GOVERNMENT SCHEMES AND SOCIAL SECURITY
GigCredit Onboarding Specification
Version: Final Input Structure
Status: Locked — Inputs Only (No Verification Logic)

--------------------------------------------------
1. PURPOSE
--------------------------------------------------

Step-6 captures the user’s participation in recognised
government schemes and social security programs.

All schemes in this step are OPTIONAL at the global level.

Per-scheme rule:
- If the user DOES NOT select a scheme → no inputs required.
- If the user selects a scheme → that scheme’s ID/reference
  field AND proof document become REQUIRED for that scheme.

Verification and validation logic are defined in a
separate Step-6 verification document.

--------------------------------------------------
2. HOW THIS STEP IS PRESENTED
--------------------------------------------------

The screen shows a vertical list of scheme modules.
Each module has:
  - A toggle: "I have this scheme" (Yes / No)
  - When Yes → expand and show ID + proof upload fields.
  - When No → module stays collapsed and ignored.

Supported schemes:
  1. PM SVANidhi (Street Vendor scheme)
  2. eShram (Unorganised Workers UAN)
  3. PM-SYM (Shram Yogi Maandhan Pension)
  4. PMJJBY (Life Insurance)
  5. PMMY / MUDRA Loan
  6. PPF (Public Provident Fund)
  7. Udyam / MSME Registration

All modules follow the same pattern:
  - Scheme Selected? (toggle)
  - Scheme ID / Reference Number
  - Scheme Document Upload

10. STEP-6 INPUT SUMMARY
--------------------------------------------------

Module            | Selection Field | ID / Reference Fields | Proof Upload Fields | Mandatory Behaviour
------------------|-----------------|------------------------|---------------------|---------------------
PM SVANidhi       | 1               | 2                      | 3                   | All Conditional Required when selected
eShram            | 4               | 5                      | 6                   | All Conditional Required when selected
PM-SYM            | 7               | 8                      | 9                   | All Conditional Required when selected
PMJJBY            | 10              | 11                     | 12                  | All Conditional Required when selected
PMMY / Mudra      | 13              | 14                     | 15                  | All Conditional Required when selected
PPF               | 16              | 17                     | 18                  | All Conditional Required when selected
Udyam / MSME      | 19              | 20                     | 21                  | All Conditional Required when selected

Global rule:
- User can select any combination of schemes.
- For each selected scheme, both the ID/reference field
  and the scheme proof upload are REQUIRED to complete
  that module.
- Step-6 itself remains OPTIONAL in terms of scoring:
  skipping all schemes does not block onboarding.
