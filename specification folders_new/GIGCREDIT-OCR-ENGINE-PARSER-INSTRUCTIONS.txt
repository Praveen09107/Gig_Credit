--------------------------------------------------------------------------------
1.1 GENERAL OCR PIPELINE (APPLIES TO ALL INPUTS)
--------------------------------------------------------------------------------

  STEP 1 — RECEIVE FILE
    Input: file path (jpg / png / pdf)
    Action: detect file type

  STEP 2 — FILE TYPE ROUTING
    if extension in ['.jpg', '.jpeg', '.png', '.webp']:
        route → IMAGE PIPELINE
    if extension == '.pdf':
        try pdfplumber text extraction first
        if text extracted and len > 100 chars:
            route → PDF TEXT PIPELINE (no OCR needed)
        else:
            route → PDF IMAGE PIPELINE (scanned, needs OCR)

  STEP 3 — IMAGE PREPROCESSING (for image pipeline and PDF image pipeline)
    a. Convert to grayscale
    b. Resize: max width 1600px (preserve aspect ratio)
    c. Deskew: correct rotation if > 2 degrees
    d. Denoise: apply mild Gaussian blur
    e. Contrast enhancement: CLAHE (Contrast Limited Adaptive Histogram Eq.)
    f. Binarize: Otsu threshold for black/white conversion

  STEP 4 — OCR EXTRACTION
    Run PaddleOCR on preprocessed image
    Returns: list of (bounding_box, text, confidence)
    Filter: discard any result with confidence < 0.60

  STEP 5 — DOCUMENT TYPE DETECTION
    From raw OCR text, detect document type (see Section 2)
    Select correct parser strategy

  STEP 6 — FIELD EXTRACTION
    Run the selected parser on the OCR text
    Extract target fields into a dict

  STEP 7 — NORMALIZE OUTPUT
    Convert extracted dict to the normalized schema for that document type
    (defined in Section 5)

  STEP 8 — CONFIDENCE SCORING
    Compute parser confidence:
      required_fields_found / total_required_fields
    If confidence < 0.70: flag as LOW_CONFIDENCE, request re-upload

  STEP 9 — CLEANUP
    Delete preprocessed temp images
    Keep only the normalized output dict in memory

  STEP 10 — RETURN
    Return normalized dict + confidence score + doc_type

--------------------------------------------------------------------------------
1.2 OCR TRIGGER RULES (WHEN TO RUN OCR)
--------------------------------------------------------------------------------

  TRIGGER — RUN OCR:
    ✅ User uploads a new file
    ✅ User replaces an existing file
    ✅ User recaptures a photo
    ✅ User taps an explicit "Rescan" button

  DO NOT TRIGGER OCR:
    ❌ User types in a text field
    ❌ User moves to the next step (if file unchanged)
    ❌ User taps the back button
    ❌ App resumes from background (use cached result)

  OCR RESULT CACHING:
    After OCR runs on a file, store result in temp cache with file hash.
    If same file uploaded again (same hash), use cached result, skip OCR.

SECTION 2 — DOCUMENT TYPE DETECTION
================================================================================

AI INSTRUCTION:
  After raw OCR text is extracted, run document_type_detect() to identify
  which parser to use. Detection is keyword-based on the full OCR text.

  def document_type_detect(raw_text: str) -> str:
    text = raw_text.upper()

    # Aadhaar detection
    if "AADHAAR" in text or "UNIQUE IDENTIFICATION" in text or "UIDAI" in text:
        if "FRONT" clue or photo area detected:
            return "AADHAAR_FRONT"
        return "AADHAAR_BACK"

    # PAN detection
    if "INCOME TAX DEPARTMENT" in text or "PERMANENT ACCOUNT NUMBER" in text:
        return "PAN_CARD"

    # Bank statement detection — detect which bank
    if "AXIS BANK" in text:
        return "BANK_STMT_AXIS"
    if "CANARA BANK" in text:
        return "BANK_STMT_CANARA"
    if "STATE BANK OF INDIA" in text or "SBI" in text:
        return "BANK_STMT_SBI"
    if "HDFC BANK" in text:
        return "BANK_STMT_HDFC"
    if "ICICI BANK" in text:
        return "BANK_STMT_ICICI"
    if any keyword in text for ["ACCOUNT STATEMENT", "TRANSACTION DATE",
                                 "DEBIT", "CREDIT", "BALANCE"]:
        return "BANK_STMT_GENERIC"

    # Utility bills
    if "TAMIL NADU ELECTRICITY" in text or "TNEB" in text or "TANGEDCO" in text:
        return "BILL_ELECTRICITY_TNEB"
    if "BESCOM" in text or "BANGALORE ELECTRICITY" in text:
        return "BILL_ELECTRICITY_BESCOM"
    if "INDANE" in text or "INDIAN OIL" in text:
        return "BILL_LPG_INDANE"
    if "HP GAS" in text or "HINDUSTAN PETROLEUM" in text:
        return "BILL_LPG_HP"
    if "BHARAT GAS" in text or "BPCL" in text:
        return "BILL_LPG_BHARAT"
    if "JIO" in text and ("POSTPAID" in text or "BILL" in text):
        return "BILL_MOBILE_JIO"
    if "AIRTEL" in text and "BILL" in text:
        return "BILL_MOBILE_AIRTEL"

    # Vehicle documents
    if "REGISTRATION CERTIFICATE" in text or "RC BOOK" in text:
        return "RC_BOOK"
    if "DRIVING LICENCE" in text or "DRIVING LICENSE" in text:
        return "DRIVING_LICENCE"

    # Platform earnings screenshots
    if "SWIGGY" in text and ("EARNINGS" in text or "TRIPS" in text):
        return "EARNINGS_SWIGGY"
    if "ZOMATO" in text and "EARNINGS" in text:
        return "EARNINGS_ZOMATO"
    if "OLA" in text and "EARNINGS" in text:
        return "EARNINGS_OLA"
    if "UBER" in text and "EARNINGS" in text:
        return "EARNINGS_UBER"

    # Government scheme cards
    if "E-SHRAM" in text or "ESHRAM" in text or "UNORGANISED WORKER" in text:
        return "ESHRAM_CARD"

    # Insurance
    if "HEALTH INSURANCE" in text or "MEDICLAIM" in text:
        return "INSURANCE_HEALTH"
    if "MOTOR INSURANCE" in text or "VEHICLE INSURANCE" in text:
        return "INSURANCE_VEHICLE"
    if "LIFE INSURANCE" in text or "LIC" in text or "PREMIUM RECEIPT" in text:
        return "INSURANCE_LIFE"

    # ITR
    if "INCOME TAX RETURN" in text or "ACKNOWLEDGEMENT" in text and "ITR" in text:
        return "ITR_ACKNOWLEDGEMENT"

    return "UNKNOWN"

  def clean_ocr_text(text: str) -> str:
    # Fix common OCR letter/number confusions
    # Only apply in NUMERIC-EXPECTED contexts
    text = text.strip()

    # In Aadhaar/PAN number fields only:
    def fix_number_field(s):
        return s.replace('O', '0').replace('I', '1').replace('l', '1')
              .replace('S', '5').replace('B', '8')

    # Normalize whitespace
    text = re.sub(r'\s+', ' ', text)

    # Normalize date separators
    text = re.sub(r'(\d{2})[-\.](\d{2})[-\.](\d{4})', r'\1/\2/\3', text)

    # Normalize currency symbols
    text = text.replace('Rs.', '₹').replace('INR', '₹')

    # Normalize amount commas (keep only decimals)
    def parse_amount(s):
        return float(s.replace(',', '').replace('₹', '').strip())

    return text

  FUZZY NAME MATCHING:
    When comparing OCR-extracted name with API-returned name:
    Use rapidfuzz.fuzz.token_sort_ratio()
    Threshold: ≥ 85 → MATCH, < 85 → MISMATCH

    from rapidfuzz import fuzz
    def names_match(name1: str, name2: str) -> bool:
        score = fuzz.token_sort_ratio(name1.upper(), name2.upper())
        return score >= 85
